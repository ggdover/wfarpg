Getting around

  • Drag empty space to move around. Scroll or pinch to zoom.
  • Double-click empty space to add a note right there.
  • Drop or paste images, videos, links, hex colors or text anywhere.
  • Drag a section by its title. Everything inside it moves along.
  • Select an item to mark it Want, Maybe or Avoid, recolor it or edit it.
  • Enter edits, Esc finishes, Delete removes, + − zoom, F fits the board.
  • Start a note line with # for a heading or - for a bullet. Wrap words in ** to bold them.
