Hero Run Portfolio

Fifty runs for the hero, each shown twice: from the side, its cycle looping as the ground goes by, and in the play demo, running about the open field from the game's camera. Every run lands heel first, the forefoot coming down a moment later, and every one runs at the hero's 5.5 m/s. All are shown on one model.

Mark the runs you like, and add a note if something about one stands out. Your marks are kept with this page, for Claude to read once you've narrowed them down. Click a clip to pause it; the speed buttons slow them all down.

To try a run yourself: python3 game/tools/play.py --script res://scripts/dev/runs.gd -- --run=heroic (Q and E step through the runs, Z slows the game down)
